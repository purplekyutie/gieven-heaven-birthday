GIEVEN & HEAVEN RSVP WEBSITE

FILES
- index.html        Home page
- invitation.html   Invitation page
- rsvp.html         RSVP form page
- location.html     Venue and Google Maps page
- style.css         Shared responsive design
- script.js         Mobile menu and RSVP form behavior
- assets/invitation.jpg  Your supplied invitation image

HOW TO OPEN
1. Extract the ZIP file.
2. Keep all files and the assets folder together.
3. Double-click index.html to open the website.
4. Use the top menu to move between pages.

IMPORTANT RSVP NOTE
The RSVP demo validates the form and saves submissions in the current browser's localStorage only.
It does NOT send responses to the event organizer or collect responses from other devices.
To receive real guest responses online, connect a backend or form service before publishing.

You can change the venue, date, or time by editing the relevant HTML page.
